System Overview

This web-based dashboard is part of an Internet of Things (IoT) and Artificial Intelligence (AI) system designed to monitor environmental parameters and predict solar position angles. The system integrates sensor-based data acquisition, machine learning models, and real-time visualization.

System Architecture

  1. IoT Layer: Environmental data such as temperature, humidity, and electrical current are collected using sensors connected to an ESP32 microcontroller.
  2. Data Layer: Sensor readings are transmitted over Wi-Fi and stored in a cloud database or prepared as historical datasets (CSV-based replay).
  3. AI Layer: Long Short-Term Memory (LSTM) and Random Forest models process the data to predict solar altitude and azimuth angles.
  4. Visualization Layer: This dashboard displays both sensor data and AI predictions in time-series form.

Data Description

  • Temperature (°C): Ambient air temperature measured near the solar panel.
  • Humidity (%): Relative humidity of the surrounding environment.
  • Current (A): Electrical current generated by the solar panel.
  • Altitude Angle (°): Predicted elevation angle of the Sun.
  • Azimuth Angle (°): Predicted horizontal direction of the Sun.

Artificial Intelligence Models

Two machine learning models are employed to predict solar position angles:

  • LSTM (Long Short-Term Memory): A recurrent neural network designed to capture temporal dependencies in time-series environmental data.
  • Random Forest: An ensemble learning method capable of modeling non-linear relationships between environmental variables and solar angles.

Data Source Mode

For demonstration and development purposes, this dashboard can operate using pre-recorded CSV data to simulate real-time data streaming. The same visualization pipeline is designed to be directly connected to a live IoT backend and AI inference service.

Academic Note

This dashboard is developed as part of an undergraduate thesis in physics instrumentation and renewable energy systems. The focus is placed on system integration, data-driven modeling, and interpretability of AI-based predictions rather than purely astronomical calculations.
